Domains. Gross = torso, arm, wrist and head features; fine = finger and hand(shape) features; all = both sets together. Each domain has its own PCA and its own models.
Dimensions. PCA on standardized kinematic features; each block is a separate PCA. Only components exceeding the permutation null and ≥ 5% variance are shown. Variance: observed ratio with 95% bootstrap percentile interval (1,000 resamples). Dimension numbers are not comparable across blocks; ≈ marks the corresponding pooled dimension.
Features. Significant features (index loading above permutation null) ranked by index loading, listed until 50% of the component’s summed index loading. +/− = sign of the loading (+: higher feature value → higher score); % = share of the component’s index loading.
Models. One Bayesian model per component: score_z ~ 0 + group + (1 | participant) + (1 | concept), Gaussian; priors Normal(0, 1) on group means, Exponential(1) on SDs and σ; 4 chains × 8,000 iterations (4,000 warm-up), adapt_delta = 0.95. Contrasts extracted with emmeans (population level) as more sign-like minus less sign-like group, in SD units of the respective PCA’s scores: negative = the more sign-like group scores lower. Conventionalization = native − gesture; acquisition = native − mean(naïve, beginner); all signers vs gesture = mean(naïve, beginner, native) − gesture. Bold = 95% CrI excludes 0; pd = probability of direction. Scores are z-scaled within each PCA, so magnitudes are not comparable across blocks. Contrasts involving gesturers are not estimable in sign-only PCAs and are omitted there.
Diagnostics. Max R̂ / min bulk ESS / number of divergent transitions per model.
