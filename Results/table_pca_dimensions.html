Dimensions. PCA on standardized kinematic features (fine + gross), fitted separately on all groups (pooled) and on signers only. Only PCs exceeding the permutation null and ≥ 5% variance are shown. Variance: observed ratio with 95% bootstrap percentile interval (1,000 resamples). PC numbers are not comparable across blocks; ≈ marks the corresponding pooled dimension.
Features. Significant features (index loading above permutation null) ranked by index loading, listed until 50% of the PC’s summed index loading. +/− = sign of the loading (+: higher feature value → higher PC score); % = share of the PC’s index loading.
Models. One Bayesian model per PC: score_z ~ 0 + group + (1 | participant) + (1 | concept), Gaussian; priors Normal(0, 1) on group means, Exponential(1) on SDs and σ; 4 chains × 4,000 iterations (1,000 warm-up). Contrasts extracted with emmeans (population level) as later/more sign-like minus earlier group, in SD units of the respective PCA’s scores: negative = the more sign-like group scores lower. Bold = 95% CrI excludes 0; pd = probability of direction. Scores are z-scaled within each PCA, so magnitudes are not comparable across blocks.
Diagnostics. Max R̂ / min bulk ESS / number of divergent transitions per model.
